Module 2 Formula Summary

The Chemist's Toolkit: Every Equation and Data Set required for the HSC

1. Core Stoichiometry Formulas

The Mole (Mass)

$$n = \frac{m}{MM}$$
  • $n$: number of moles (mol)
  • $m$: mass (g)
  • $MM$: molar mass (g/mol)

The Mole (Particles)

$$n = \frac{N}{N_A}$$
  • $N$: number of particles
  • $N_A$: Avogadro's constant ($6.022 \times 10^{23} \text{ mol}^{-1}$)

Percentage Yield

$$\% \text{ Yield} = \frac{\text{Actual}}{\text{Theoretical}} \times 100$$

Note: Both values must be in the same units (moles or mass).

2. Concentration & Solutions

Molarity (M)

$$c = \frac{n}{V}$$
  • $c$: concentration (mol/L or M)
  • $V$: volume in Litres (L)

Dilution Formula

$$c_1V_1 = c_2V_2$$
  • Subscript 1: Initial (Stock) state
  • Subscript 2: Final (Diluted) state

Concentration (g/L)

$$c_{g/L} = \frac{m}{V}$$

To convert mol/L to g/L: multiply by Molar Mass.

3. Gas Laws

Ideal Gas Law

$$PV = nRT$$
  • $P$: Pressure (kPa)
  • $R$: Gas Constant ($8.314 \text{ J K}^{-1}\text{mol}^{-1}$)
  • $T$: Temperature (Kelvin, $K = ^\circ C + 273.15$)

Combined Gas Law

$$\frac{P_1V_1}{T_1} = \frac{P_2V_2}{T_2}$$

Used when $n$ (moles) is constant.

Gay-Lussac's (Volume Ratio)

$$V \propto n$$

For reactions involving only gases at constant $T$ and $P$, volumes react in whole number ratios.

4. Solubility Rules (NAGSAG)

Essential for predicting precipitates in stoichiometry and identifying spectator ions.

Rule / Ion Solubility Exceptions
Nitrates ($NO_3^-$) Always Soluble None
Acetates ($CH_3COO^-$) Always Soluble None
Group 1 Ions ($Li^+, Na^+ \dots$) Always Soluble None
Sulfates ($SO_4^{2-}$) Soluble $Pb^{2+}, Ba^{2+}, Sr^{2+}, Ca^{2+}$
Ammonium ($NH_4^+$) Always Soluble None
Group 17 (Halides: $Cl^-, Br^- \dots$) Soluble $Ag^+, Pb^{2+}, Hg_2^{2+}$
Carbonates ($CO_3^{2-}$) / Phosphates ($PO_4^{3-}$) Insoluble Group 1 and $NH_4^+$
Hydroxides ($OH^-$) Insoluble Group 1, $NH_4^+$, $Ba^{2+}$, $Sr^{2+}$
